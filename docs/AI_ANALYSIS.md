# Why Now и Recommended Actions

Откройте «Новости» → «Подробнее». Под описанием и ссылкой открыто показаны Why Now (почему событие важно) и Recommended Actions (конкретные шаги команды).

## Без API-ключа

При первом запуске доступны шесть сохранённых публикаций с индивидуальными авторскими разборами и тремя рекомендациями для каждой. Повторно открыть их можно через «Источники» → «Открыть подготовленную подборку». Это не вызывает API и не удаляет избранное или заметки. Даты публикаций не изменяются. Разборы — примеры интерпретации, не новые факты из источников; метод указан в объяснении оценки.

## AI-анализ

1. Откройте «Источники» и вставьте **ключ OpenRouter** в скрытое поле. Ключ другого провайдера напрямую не поддерживается.
2. В «Настройках анализа» при необходимости укажите модель, темы команды и лимит публикаций.
3. Нажмите «Запустить AI-анализ подборки», чтобы обработать текущие новости. Для анализа новых RSS или импортированного файла включите «ИИ-анализ» перед обновлением/импортом.
4. Откройте «Новости» → «Подробнее» для просмотра результата.

Тексты и контекст команды передаются OpenRouter и выбранному поставщику модели только при явном запуске. Запросы могут расходовать баланс. Указанный ключ ещё не означает успешное подключение. Ошибки авторизации, баланса и формата ответа отображаются; неуспешный ответ не выдаётся за AI-анализ.

Ключ хранится только в памяти сессии Streamlit, не записывается в SQLite, историю, экспорт или код. При переходе между страницами сохраняется, при выходе из аккаунта очищается. Кнопка «Очистить введённый ключ» очищает поле. При наличии серверного OPENROUTER_API_KEY пустое поле использует серверный ключ; для его отключения удалите настройку на сервере. Введённый пользователем ключ имеет приоритет.

Подготовленный разбор используется только для точного совпадения сохранённой публикации и не перезаписывает успешный ответ ИИ. Кэш учитывает текст, модель и профиль команды. Избранное в Markdown включает оба новых блока.

Платные API при подготовке архива не вызывались. Проверки интеграции используют имитацию ответов.
